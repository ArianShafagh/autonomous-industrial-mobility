\chapter{Configuration Parameters}
\label{app:configuration}

Every number the system uses is declared in one file, \file{src/robofetch\_factory/config/params.yaml};
nothing numeric is hard-coded. A scenario file overrides any subset of these values, and a key that
does not exist is rejected when the configuration is loaded, so a typo fails loudly instead of
silently leaving the default in place.

The tables below are \emph{generated} from that file by
\file{tools/thesis/gen\_appendix.py}, so they cannot drift from the system that produced the
results in \cref{ch:results}. The geometry of the hall is the one thing not listed here: it lives
in \file{layout.yaml} (\cref{sec:single-source}), because the world and map generator needs it.
